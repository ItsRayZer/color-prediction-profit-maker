Battery Optimization Guide
Prevent mobile OS from putting WebSocket to sleep
Xiaomi / Redmi / POCO (MIUI / HyperOS)

Settings → Apps → Manage Apps → Chrome/Browser → Battery Saver → Select "No Restrictions". Enable "Autostart".

Samsung Galaxy (One UI)

Settings → Apps → Chrome/Browser → Battery → Select "Unrestricted". Ensure it is removed from "Deep Sleeping Apps".

Realme / OPPO / OnePlus (ColorOS)

Settings → Battery → App Battery Management → Chrome/Browser → Allow "Foreground & Background Activity".

Apple iPhone & iPad (iOS)

Tap Share in Safari → "Add to Home Screen" to run in dedicated standalone PWA container without background throttling.
