Battery Optimization Guide

Prevent OS from suspending background calculations

Android (Samsung / Xiaomi / Pixel / OnePlus)
1

Long-press browser or 01:01 icon on home screen → Tap App Info (ℹ️).

2

Tap Battery or App Battery Usage → Select Unrestricted (or "Don't Optimize").

3

Open Recent Apps → Tap the app header icon and select Lock app 🔒 to prevent system cleanup.

iOS / Safari (iPhone & iPad)
1

Install as Home Screen app: Tap Safari Share → Add to Home Screen.

2

Ensure Background Keep-Alive is toggled ON. The silent audio buffer keeps Safari's engine running in background.

3

Disable Low Power Mode when running automated long betting sessions.
