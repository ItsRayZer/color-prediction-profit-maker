Battery Exemption Guide

Prevent OS from pausing WebSocket & Keep-Alive

Xiaomi / Redmi / POCO (MIUI / HyperOS):

Settings → Apps → Manage Apps → Chrome/Browser → Battery Saver → Select "No Restrictions". Also turn ON "Autostart".

Samsung (One UI):

Settings → Apps → Chrome/Browser → Battery → Select "Unrestricted". Ensure it is removed from "Sleeping Apps".

Realme / OPPO / OnePlus (ColorOS):

Settings → Battery → App Battery Management → Chrome/Browser → Allow "Foreground & Background Activity".

Apple iPhone (iOS):

Settings → Safari → Advanced → ensure JavaScript is ON. Add to Home Screen (PWA) for dedicated background lifecycle.
